## 容易踩的四处

1. **「有行」≠「有内容」**：日记页每天自动建 `total=0` 的占位行（标题固定），
   把它算成有记录会让文字覆盖率凭空 100%。覆盖率一律按「有内容」计。
   另外 `OneDayPage.save()` 会重算 `total = oneday + page`，造数时别直接传 `total`。
2. **当前月不进月粒度分母**：月度记录是月结动作，本月没过完就不算缺失。
   否则每月初打开页面，财富覆盖率都会无故掉一档。
   但**单月视角**的强度分母必须是 1（这个月有没有记），不是全年月数。
3. **算不出来就给 `null`**：未来年份、零期数时覆盖率是 `null`（界面 `—`），
   **不是 0%**；「还没发生」和「发生了但没记」必须能分开。
4. **度量要选对载体，不是堆图形编码**：月度视图的覆盖率用**文字**（要读准、要比较），
   强度用**底色深浅**（它是「厚不厚」的感觉量）。曾试过「柱高 = 强度 + 颜色 = 覆盖率」，
   读者要先读长短再读色相才能拼出一个月，多一步就是「看不懂」。
   强度**按行归一**（跨行不比深浅），提示框里给真实数字（如 `19,876 步/天`）。
