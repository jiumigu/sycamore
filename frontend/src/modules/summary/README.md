## 容易踩的四处

1. **「有行」≠「有内容」**：日记页每天自动建 `total=0` 的占位行（标题固定），
   把它算成有记录会让文字覆盖率凭空 100%。覆盖率一律按「有内容」计。
   另外 `OneDayPage.save()` 会重算 `total = oneday + page`，造数时别直接传 `total`。
2. **当前月不进月粒度分母**：月度记录是月结动作，本月没过完就不算缺失。
   否则每月初打开页面，财富覆盖率都会无故掉一档。
   但**单月视角**的强度分母必须是 1（这个月有没有记），不是全年月数。
3. **算不出来就给 `null`**：未来年份、零期数时覆盖率是 `null`（界面 `—`），
   **不是 0%**；「还没发生」和「发生了但没记」必须能分开。
4. **度量要选对载体，不是堆图形编码**：月度视图的覆盖率用**文字**（要读准、要比较），
   强度用**底色深浅**（它是「厚不厚」的感觉量）。曾试过「柱高 = 强度 + 颜色 = 覆盖率」，
   读者要先读长短再读色相才能拼出一个月，多一步就是「看不懂」。
   强度**按行归一**（跨行不比深浅），提示框里给真实数字（如 `19,876 步/天`）。

## 阶段带与阶段对照的三处坑（v3.64.61）

1. **阶段带放月份行上方**，不能放数据行下面 —— 下方紧贴「财富」，会被读成
   那一行的标题。字号小一号、无 hover 高亮：它是背景说明，不是第 8 个维度。
2. 一个月内**可能切换**（`is_mixed`）、也**可能没有任何阶段**（`reason`）。
   前者印主段名 + 「切换」并给逐段日期，后者印「未配置」且**不回退成上一段的名字**
   —— 那会凭空延长一段人生。整年都没阶段时一句话跨 12 列说完，不铺 12 个「未配置」。
3. `is-none` 有 1px 虚线边框 ⇒ 必须 `box-sizing: border-box`，否则它比相邻实心格子
   高 2px，整条带子高低不齐（这种 2px 只有截图才看得出来）。

## 配对体检与身体-状态的两处坑（v3.64.62）

1. **必须先关 `loading` 再 `nextTick`，才能在回调里 init 图表**：

   ```js
   finally { loading.value = false }
   // 🔴 关早了没用、关晚了才致命：loading 还为 true 时 v-else 分支没渲染，
   //    chartRef.value 是 undefined，renderChart 会静默 return —— 页面上是一个 340px 的空白块，控制台零报错
   await nextTick()
   renderChart()
   ```

2. **两种「空」要分开说，别合成一句话**：`nightsTotal === 0`（一天都没记）给 info + 空态按钮；
   `< 5`（记了但太少）给 warning。`MIN_FOR_TREND = 5`，不是 3 ——
   52 周窗口下 3 个点连成的线必被读成趋势。

另外两条：

- 散点**各按自身 min/max 归一**，两列不同量纲不共享刻度；两列并排本来就是「看形状」，不是「比高低」。
- `<BodyMindChart />` 曾被注释掉。**注释掉的原因从来不是接口没就绪，是数据不够**（全库 4 条自检）。
  代码注释掉的组件在界面上看起来和「这功能没做」完全一样 —— 要么给空态、要么别留注释块。

## 年度回顾叙事（v3.64.63）

入口：年度明细弹窗每行的「读这一年 →」，**在同一个弹窗内切换视图**，顶部「← 年度明细」回来。

- 🔴 **不叠第二层弹窗**：嵌套 `el-dialog` 要各自处理 `append-to-body` 与层级，
  关掉上层还会把下层一起带走。同框切换 + `@closed` 复位即可。
- 宽度跟着态走：表格 `960`、叙事 `780`。叙事是一列长文，960 宽的行读起来太散。
- 阅读栏 `max-width: 700px`，内容区 `max-height: min(58vh, 560px)` 内部滚动。

### 三处容易做错的

1. **引文块不是按钮**。这些记录没有逐条跳转的入口，做成按钮等于给一个点不动的假出口。
   用左竖线的引文样式（`blockquote`）就够了 —— 引用成立的点是「能看到那条记录是什么」。
2. **空态四种原因分开说**：`future` / `no_data` / `sparse_data` / `few_events`，
   加上「读取失败」。混成一句「暂无数据」等于没说。
3. 🔴 **真机点「返回」要限定在弹窗内**：页头也有一个「年度明细」按钮，
   它在遮罩背后，`getByRole` 会先匹配到它 ⇒ 点击被遮罩拦下、报「intercepts pointer events」。
   写自动化脚本时用 `page.locator('.el-dialog').getByRole(...)`。
